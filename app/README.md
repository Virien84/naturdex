# NaturDex · app

The PWA that runs on the phone: React + Vite + vite-plugin-pwa + onnxruntime-web.

```sh
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
```

| File | What it does |
|---|---|
| `src/data/tripData.js` | "Prepare trip": downloads the model and species list into Cache Storage, for offline use. Production builds take the model from [Hugging Face](https://huggingface.co/Virien/naturdex-bioclip-onnx) via `VITE_MODEL_URL` in `.env.production`. |
| `src/ml/classifier.js` | Runs BioCLIP's image encoder (ONNX, WASM) and compares the photo with the precomputed species embeddings. Confidence thresholds and the precaution rule (see [../SAFETY.md](../SAFETY.md)). |
| `src/ml/photoQuality.js` | Blurry / too dark check (variance of the Laplacian), before running the model. |
| `src/data/db.js` | The album, in IndexedDB. Nothing leaves the phone. |
| `src/data/location.js` | GPS position, coarsened to ~10 km for threatened species. |
| `src/screens/` | Camera, My NaturDex, Prepare trip. |

The model and species files in `public/` are generated by [`../embeddings`](../embeddings).

## Deploy

Pushing to `main` runs [`../.github/workflows/deploy.yml`](../.github/workflows/deploy.yml): `npm ci`, `npm run build`, and publish `dist/` to GitHub Pages at https://virien84.github.io/naturdex/. `base: './'` in `vite.config.js` makes the build work from that sub-folder.

The model is not in the repo, so the deployed site does not contain it; "Prepare trip" downloads it from Hugging Face (the URL is in `.env.production`). `npm run dev` keeps using the local copy in `public/models/`.
